# Task 4 fix round 2 report

Status: DONE

Base: `088fcc3`

## Implemented

1. Added one account-database authority for the effective user's validated
   home directory. Production CLI and daemon SSH paths now use that authority
   and ignore mutable `HOME` and `XDG_CONFIG_HOME`. The managed config,
   `~/.ssh/config`, `ssh-config path`, CLI `-F` config, daemon files, and offer
   receipt consequently resolve below the same account home OpenSSH uses.
   Explicit-home constructors remain available only as test injection seams.
2. Closed the second-editor rollback race. Rollback verifies that the target
   is still Gas Can's exact staged inode and bytes before exchange, then
   verifies the staging entry again before cleanup. If a newer editor wins,
   its bytes remain the live target and displaced editor bytes move without
   unlinking to the deterministic
   `.gascan-recovery-<target>-<device>-<inode>` entry.
3. Classified a no-follow directory-open `EACCES` (`Errno::ACCESS`) as
   `ssh_config_unsafe`, alongside `ELOOP` and `ENOTDIR`. Other ordinary safe
   update I/O errors remain `ssh_config_update_failed`.

The exact three-line include block and all accepted Task 1–4 lifecycle,
publication, redaction, and presentation behavior remain unchanged. No Task 5,
image, live, release, offline SSH, bridge, proxy, or listener work was added.
